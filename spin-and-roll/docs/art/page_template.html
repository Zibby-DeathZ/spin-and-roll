Getting them into the game

  1. Save each picture with the exact name shown (lower case, dashes). PNG for people, monsters and items; JPG for maps, portraits, the storybook and the puzzle.
  2. Put it in that folder inside your spin-and-roll\spin-and-roll project. The art folders are new; create them if they aren't there.
  3. Commit and push in GitHub Desktop. After the deploy, press Ctrl+F5.
  4. On the GM screen, the Media tab lists every file and ticks off the ones it finds.
