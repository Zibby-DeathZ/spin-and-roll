# Spin & Roll: image prompts for The Hollow Heir

Every picture the players see. Paste a prompt into your image tool, save the result with the exact file name shown, and put it in that folder inside `spin-and-roll/`. Anything without a picture keeps its emoji, so add them in any order.

Check what you have on the GM screen: **Media** tab, file checklist.
