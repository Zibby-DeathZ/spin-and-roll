# Sounds

Sound effects are built into the app; no files are needed for them.

## Music: `public/sounds/music/`
Loops played on the TV. Name them exactly like this (.mp3):

| File | Used for |
|---|---|
| intro.mp3 | The opening cutscene (plays automatically) |
| castle.mp3 | Castle halls |
| great-hall.mp3 | Great Hall feast |
| diagon.mp3 | Diagon Alley |
| mystery.mp3 | Mystery and clues |
| forest.mp3 | Forbidden Forest |
| battle.mp3 | Battle |
| undercroft.mp3 | The Undercroft |
| victory.mp3 | Victory |

Use music you're allowed to use: royalty-free libraries (for example Pixabay Music),
or Creative Commons tracks with attribution (for example Kevin MacLeod / incompetech).
Check each track's licence. Film soundtracks are copyrighted.

## Narration (optional): `public/sounds/narration/`
Record yourself reading each storybook page: page-1.mp3 … page-6.mp3.
If a file is missing, the page is silent and you read it live from the GM screen.
